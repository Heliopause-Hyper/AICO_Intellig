# CORCA Lab Templates

This directory is reserved for experimental CORCA templates that should not modify
the stable templates in `templates/corcasim/`.

Rules:
- copy from `templates/corcasim/` only when a lab script proves the need;
- keep names explicit, e.g. `state_family_v1.json`;
- do not overwrite `default.json`, `burnup.json`, or `xenon.json`;
- document any new output keys next to the template that introduces them.
