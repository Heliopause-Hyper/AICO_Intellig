**AICO-Intellig 大规模扩跑补强：2026-09-15**

对象：
- 严格 `v4` 大样本主结果：`results/complexity_study/shared_subspace_strict_v4_xlarge_k3.json`
- 严格 `v4` 更高共享维度：`results/complexity_study/shared_subspace_strict_v4_xlarge_k5.json`
- 严格 `v4` 更长预算：`results/complexity_study/shared_subspace_strict_v4_xlarge_budget360.json`
- 更高维 synthetic scaling：`results/complexity_study/shared_subspace_synthetic_xlarge_v2.json`
- 更大失配扫描：`results/complexity_study/shared_subspace_mismatch_xlarge_v2_d128.json`

这轮补强的目标不是增加同类小样本重复，而是直接回答四个尚未完全封口的问题：
1. 严格 `v4` 的主结论在更大样本下是否稳定；
2. 优势是否只发生在 `k=3` 这一特定共享维度；
3. 优势是否只是低预算效应，预算翻倍后基线会不会追回来；
4. 失配下的退化是否是渐进的，还是一旦偏离共享结构就迅速失效。

**一、严格 `v4` 大样本主结果：`k=3`**

配置：
- `d in {32, 64, 128, 256}`
- `family_seeds = 30`
- `history_tasks = 8`
- `validation_tasks = 10`
- `test_tasks = 30`

- `3,600` 个目标任务 / method

- `scratch_random_direction`: regret `0.0647`

`d=64`
- `scratch_coordinate_fd`: regret `0.1593`
- `scratch_random_direction`: regret `0.1352`

- `estimated_subspace`: regret `0.0066`

`d=128`
- `scratch_coordinate_fd`: regret `0.1538`
- `scratch_random_direction`: regret `0.2367`
- `history_probe_init_random_direction`: regret `0.1510`
- `estimated_subspace`: regret `0.0066`

`d=256`
- `scratch_coordinate_fd`: regret `0.3569`

在阈值 `0.02` 下，`d=256` 的成功率分别为：

**这组结果说明**

可以更有力地说：
- 严格 `v4` 的主结论不是小样本波动；
- 在样本量显著放大后，结构方法的优势几乎不动；
- 随维度升高，当前测试的三类对照方法继续恶化，而估计子空间方法仍稳定在约 `0.0066 ~ 0.0067`。

**四、更高维 synthetic scaling：扩到 `d=512`**

配置：
- `d in {16, 32, 64, 128, 256, 512}`
- `k = 3`
- `family_seeds = 30`
- `history_tasks = 10`
- `test_tasks = 40`
- `budget = 180`

总规模：
- `7,200` 个目标任务

代表性结果：

- `d=16`: scratch `0.1639`, estimated `0.0088`
- `d=32`: scratch `0.1628`, estimated `0.0130`
- `d=64`: scratch `1.4259`, estimated `0.0173`
- `d=128`: scratch `0.6932`, estimated `0.0073`
- `d=256`: scratch `1.3199`, estimated `0.0093`
- `d=512`: scratch `2.0951`, estimated `0.0162`

在阈值 `0.02` 下，`estimated_subspace` 的成功率在各维度均约为 `0.95` 以上。

**这组结果说明**

可以更稳地表述：
- 共享结构收益不是止步于 `d=256`；
- 在当前 synthetic family 中，估计子空间方法的 regret 随维度增长仍保持在很窄的带宽内；
- 相比之下，scratch 方法在更高维度上明显恶化。

**五、更大的失配扫描：`d=128`**

配置：
- `d = 128`
- `k = 3`
- `family_seeds = 30`
- `history_tasks = 8`
- `test_tasks = 40`
- `budget = 180`
- `probe_points in {1, 2, 4, 8}`
- `angles in {0, 5, 15, 30, 45, 60}`
- `ambient_curvatures in {0.005, 0.01, 0.02, 0.05, 0.1}`

总规模：
- `120` 个 misspecification 条件
- `14,400` 个目标任务 / method

按 ambient curvature 汇总后的 `estimated_subspace` 平均结果：
- `0.005`: regret `0.0198`, success@`0.02` `0.8782`
- `0.01`: regret `0.0216`, success@`0.02` `0.8698`
- `0.02`: regret `0.0215`, success@`0.02` `0.8581`
- `0.05`: regret `0.0279`, success@`0.02` `0.7992`
- `0.1`: regret `0.0341`, success@`0.02` `0.7049`

**这组结果说明**

可以更准确地说：
- 结构失配确实会削弱迁移收益；
- 但当前观察到的是渐进退化，而不是在轻中度失配下立即失效；
- 这为后续建立失配边界或摊销前沿提供了更稳的经验基础。

**六、这轮扩跑后可以更硬地说什么**

当前证据已经支持以下更强表述：

1. 在严格 `v4` 协议下，结构迁移优势并不是小样本现象；大样本扩跑后结论依旧稳定。
2. 该优势不是 `k=3` 的单点特例；在更高共享维度 `k=5` 时依旧成立。
3. 该优势也不是低预算错觉；目标预算翻倍后，原空间基线没有追回主差距。
4. 在当前 synthetic family 中，共享结构收益已经被直接扩展验证到 `d=512`。
5. 在更大规模失配扫描下，收益存在清晰但渐进的退化边界，而非一触即溃。

**七、仍然保留的边界**

1. 这些结论依旧是受控合成环境中的高维证据，不是一般黑箱优化的普适结论。
2. 当前无历史对照虽然比之前更完整，但仍只覆盖有限机制。
3. 真实档案侧已经有事件级可用族，但它们仍偏低维，尚不能承担高维复杂度主张。
4. 当前更大的实验矩阵仍主要在同一共享结构生成机制内，尚未系统检验更广的分布外泛化。
